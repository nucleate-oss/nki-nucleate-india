# Contributing

## Branches

`feature/<short-description>`, `fix/<short-description>`, `chore/<short-description>`.

## Commits

[Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`,
`chore:`, `docs:`, `test:`, `refactor:`.

## Pull requests

Every PR into `main` needs at least one approving review and green CI
(`ruff check .`, `black --check .`, `pytest`) before it can be merged.
